Utopia

Utopia is a clean and versatile serif font family, designed by Robert Slimbach at Adobe in the 1980s and licensed as as free font since 2006.

This project provides web support for Utopia, specifically, WOFF2 files and CSS definitions. View the font files and source on GitHub.

History

Utopia began as a proprietary font, but Adobe licensed it as a free font to the TeX Users Group (TUG, a community organization for TeX and LaTeX). TUG sublicenses Utopia as a free font to all. The license is custom and differs slightly from the standard SIL Open Font License.

Utopia is free in its normal and bold variations (regular and italic). Adobe and other font vendors still sell commercial licenses for the full range of weights (100 to 900).

Usage

Use Utopia in your website by linking the font face stylesheet in head. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/bhushan-mohanraj/utopia/dist/utopia.css">

Then, set the font family to Utopia. A simple website would look like: 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">

    <title>Utopia</title>

    <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/bhushan-mohanraj/utopia/dist/utopia.css">

    <style>
      body {
        font-family: Utopia, serif;
      }
    </style>
  </head>
  <body>
    <h1>Hello, world</h1>

    <p>
      A simple website using Utopia.
    </p>
  </body>
</html>
